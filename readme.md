# Evaluación 2 - Sistema de Reservas de Salas

## Descripción general

Este proyecto corresponde a un sistema de administración de reservas de salas. Está compuesto por un frontend desarrollado en React y un backend desarrollado con Node.js, Express, MySQL y Sequelize.

El sistema permite iniciar sesión, gestionar usuarios, administrar salas y crear reservas, consumiendo endpoints independientes del backend.

## 2. Backend

### Descripción

El backend corresponde a la API RESTful del sistema de reservas de salas. Fue desarrollado con Node.js, Express, MySQL y Sequelize. Su función es manejar la lógica del sistema, la conexión con la base de datos, la autenticación de usuarios y los endpoints utilizados por el frontend.

### Tecnologías

- Node.js
- Express
- MySQL
- Sequelize ORM
- Sequelize CLI
- JWT
- bcryptjs
- dotenv
- cors
- nodemon
- Postman


### EJECUTAR
```bash
npm.cmd run dev
